# 気象庁防災情報XMLの概要（2026年11月27日調べ）

GIS・WebGISで使える形にするために、防災情報XMLの種類と量、場所の表し方を整理する。

- 情報源: 気象庁「防災情報XML一覧表（表1.1）」2026年11月18日版（`data/ref/`）
- 実測: 長期フィード4本（2026-11-19〜11-26、約7日分）の全エントリと、種類ごとに1通ずつ取った実物の電文（`data/survey/`）
- 集計スクリプト: `scripts/survey.py`、結果: `data/survey_summary.json`

## 3. 場所の表し方による分類（GIS化の観点）

**電文の種類で分けるより、場所の表し方で分けるほうがGIS化の手間がそろう。** 実物を見ると、次の4つに収まった。

### A. 地域コード → 予報区等GISデータと結び付けて面にする（最多）

`<Area><Name/><Code/></Area>` の形でコードを持つ。コードの種類は親要素の `codeType` 属性に書かれるが、**書かれていない電文もある**（VPFD51・VPWP50・VPCY51）。その場合はコードの桁数と電文の種類から判断する必要がある。

| codeType（電文に書かれている値） | 桁数の例 | 結合先の予報区等GISデータ | 使っている電文 |
|---|---|---|---|
| 気象・地震・火山情報／市町村等 | 7桁 `1310100` | 市町村等（気象警報等） | 警報・注意報（VPWW53〜61）、集約通報 VPWS50、時系列 VPWP50、土砂災害警戒情報 VXWW50、竜巻注意情報、降灰予報 |
| 気象情報／府県予報区・細分区域等 | 6桁 `130010` | 府県予報区等、一次細分区域等 | 警報・注意報、府県天気予報 VPFD51、警報級の可能性・早期注意情報、府県気象情報 |
| 全国・地方予報区等 | 6桁 `010000` | 全国・地方予報区 | 1か月・3か月予報、早期天候情報、全般・地方の解説情報 |
| 地方海上予報区 | 4桁 `6010` | 地方海上予報区 | 地方海上警報・予報 |
| 地震情報／細分区域 | 3桁 | 地震情報／細分区域 | 震度速報 |
| 火山名 | — | （GISデータなし。火山の位置を別に用意する） | 火山関係 |

### B. 座標・図形が電文に入っている → そのまま点・線・面にする

`jmx_eb:Coordinate`、`jmx_eb:Line`、`jmx_eb:Polygon` で、ISO 6709 形式の文字列（例: `+35.7+139.8-10000/`）を持つ。

| 電文 | 図形 |
|---|---|
| 震源に関する情報 VXSE52、震源・震度に関する情報 VXSE53 | 震源の点 |
| 地上実況図・予想図 VZSA50/60、VZSF50/51/60/61 | 前線・等圧線の線、高低気圧の点 |
| 全般海上警報 VPZU52/54 | 海域の面・線、低気圧などの中心点 |
| 降灰予報（定時） VFVO53 | 降灰範囲の面（市町村コードも併用） |

### C. 観測地点のコード → 地点表と結び付けて点にする

| 電文 | 地点の種類 |
|---|---|
| 府県天気予報（R1） VPFD51 の地点予報、府県週間天気予報 VPFW50 | アメダス地点 |
| 地方季節予報（2週間気温予報） VPCK70 | 地点（73地点） |
| 季節観測 VGSK50、生物季節観測 VGSK55 | 国際地点番号 |
| 府県気象解説情報（潮位） VMCJ55 | 潮位観測地点番号 |

### D. 文章が中心 → 発表した区域に文章を属性として付ける程度

府県天気概況 VPFG50、府県・地方・全般気象情報 VPFJ50/VPCJ50/VPZJ50、潮位情報 VMCJ50〜52、全般季節予報 VPZK70 など。地図にする価値は低い。

## 4. 移行期で注意すること

- **警報・注意報は新旧が並行して配信されている。** 旧: VPWW53・VPWW54（令和10年度に廃止予定）。新: R06系で現象ごとに分かれる（大雨 VPWW55、土砂 VPWW56、高潮 VPWW57、暴風 VPWW58、波浪 VPWW59、大雪 VPWW60、その他注意報 VPWW61）。全国をまとめた集約通報 VPWS50 と時系列情報 VPWP50 もある。
- **令和10年度に廃止予定のものが多い**: 府県天気予報（無印 VPFD50）、土砂災害警戒情報 VXWW50、記録的短時間大雨情報 VPOA50、府県・地方・全般気象情報、潮位情報、警報級の可能性（明日まで）VPFD60 など。これから作るなら、R06系・R1系などの新しい電文を軸にする。
- **台風解析・予報情報**（3日予報 VPTW40〜45、5日予報 VPTW50〜55）は令和8年度に廃止予定。H30版（VPTW60〜65）が残る。

## 6. GIS化の進め方への示唆

1. **電文の種類ごとではなく、場所の表し方（A〜D）ごとに変換器を作る。** Aは「コード → 予報区等GISデータ」の結合表、Bは ISO 6709 の解析器があれば、多くの電文に効く。
2. **最初の題材は警報・注意報（A）。** 量が多く、地図にする価値が最もわかりやすい。新旧のどちらを使うか（R06系か、集約通報 VPWS50 か）を決める必要がある。
3. **VPWP50 と VPWS50 は重い。** 必要なとき以外は取らない。取るなら、高頻度フィードで差分だけ取り、同じファイルを二度取らない。
4. 地震（B）と天気図（B）は、結合データが要らないので、Aの次に手早く地図にできる。
