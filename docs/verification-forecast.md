# 検証: 府県天気予報（R1）を全国分取得し、Web 地図で表示できるか（2026年11月27日）

**結論: できる。** 全国56官署の最新の府県天気予報（R1）を取得し、区域予報を一次細分区域の面に、地点予報をアメダス地点の点に、過不足なく結合できた。MapLibre の Web 地図で、日ごと・3時間ごとの天気と気温を表示できた。

『お天気ダッシュボードを作る』（本書）が東京の1区域・1地点だけを表で見せていたのと同じ電文を、全国の地図にしたもの。

## 使ったもの

| もの | 中身 |
|---|---|
| 電文 | 府県天気予報（Ｒ１）VPFD51。定時の長期フィードから、発表官署ごとに最新の1通（56通、2026-11-27 04:31〜07:48 発表、合計約2.4MB） |
| 区域の形 | 予報区等GISデータ「一次細分区域等」`20190125_AreaForecastLocalM_1saibun_GIS.zip` |
| 地点の位置 | 気象庁のアメダス地点表 `amedastable.json`（緯度経度は度・分） |
| 処理 | `src/jma_bosai_xml/fetch.py`（取得。取得済みの電文は取りにいかない）、`src/jma_bosai_xml/timeseries.py`（時系列を平らにする。電文の種類によらない）、`scripts/build_weather_map.py`（結合して地図用のデータにする） |

## 結果

| 項目 | 結果 |
|---|---|
| 平らにした行 | 11,116（場所 × 項目 × 時刻） |
| 区域予報の区域 | 142。一次細分区域の GIS とすべて一致（名前も全一致）。GIS に残った1区域はコードのない埋立地（うるま市・金武町境界部） |
| 地点予報の地点 | 171。アメダス地点表にすべてある |
| 取れた項目 | 日ごとの天気・天気予報用テロップ番号・詳細な予報文、風、6時間ごとの降水確率、3時間ごとの天気・風向・風速階級、朝の最低気温・日中の最高気温・最高気温、3時間ごとの気温 |
| Web 地図用のデータ | 0.48MB（区域の形を簡略化し、約2km²未満の島を除いたもの。値は電文のまま） |

## わかったこと

1. **時系列は「TimeDefines + refID」の形で共通。** 値の要素が `refID` で時刻を参照するので、電文の種類を問わず「場所 × 項目 × 時刻」の縦長の表にできた（`timeseries.py`）。週間天気予報など、ほかの時系列の電文にも同じ処理が使えるはず（未確認）。
2. **区域予報と地点予報は電文の中で結び付いていない。** どの地点がどの区域に属するかは書かれていない。地図では区域の面と地点の点を別々に置けばよいが、「区域の天気＋その区域の気温」を1つにまとめたいときは、位置で重ねて判断する必要がある。
3. **地域コードの種類（codeType）は書かれていないが、問題にならなかった。** 区域予報は6桁＝一次細分区域、地点予報は5桁＝アメダス地点で、電文の中で一貫していた。
4. **発表時刻によって入っている値が違う。** 5時発表では、今日の「朝の最低気温」がない（もう過ぎているため）。明後日の天気は17時発表にだけ入る。地図では、値がない所を「−」と表示する。
5. **降水確率の `condition` 属性は「雨」「雨か雪」などの降水の種類。** 値がない理由ではない。
6. **一次細分区域の GIS は2019年版で、ファイル名が Shift_JIS、属性は UTF-8、.prj なし。** 2019年版のまま、2026年11月の電文のコードとすべて一致した。
7. **一次細分区域の海岸線は細かすぎて、Web 地図にそのまま使えない。** 簡略化しただけでは 8.9MB あった。小さな島を除いてから簡略化して 0.48MB にした。

## Web 地図

検証用に、MapLibre でお天気ニュース風の地図を作った（このリポジトリには含めていない。リポジトリに入れるときは TypeScript で作る）。

- 区域を天気で塗り分け、天気アイコン（晴れ・くもり・傘・雪だるま。テロップ番号と天気の文から自前で描く）を置く
- 官署ごとの代表地点に、最高・最低気温のカードを出す
- 「今日・明日・3時間ごと」を切り替え、3時間ごとはスライダーで時刻を動かす
- 区域を押すと、日ごとの天気（テロップ番号つき）、3時間ごとの天気、6時間ごとの降水確率を出す

## 課題

- 区域予報と地点予報の対応づけ（わかったこと 2）
- 一次細分区域の簡略化した形は、隣の区域との境界がずれることがある（区域ごとに簡略化しているため）。境界を共有したまま簡略化する（トポロジーを保つ）か、PMTiles にする
- 府県天気予報は1日3回の定時発表。発表官署ごとに時刻が少しずつ違うので、全国を同じ時刻の予報としてそろえることはできない（地図には発表時刻の範囲を出した）
